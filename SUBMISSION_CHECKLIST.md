# CodeAlpha Submission Checklist

Before submitting Task 1:

- [ ] Run `npm ci`, `npm run check`, and `npm run build` from `frontend/`.
- [ ] Deploy Hosting + Firestore rules/indexes.
- [ ] Complete every case in `docs/TEST_PLAN.md` on the deployed URL.
- [ ] Capture screenshots/video evidence.
- [ ] Create the GitHub repository using the required `CodeAlpha_ProjectName` naming pattern (recommended: `CodeAlpha_CloudDedup`).
- [ ] Upload source code without `node_modules`, local environment files, caches, or private credentials.
- [ ] Post the project explanation video on LinkedIn with the GitHub repository link, following the internship instructions.
- [ ] Submit the completed task through the CodeAlpha submission form shared in the WhatsApp group.
- [ ] Complete at least one additional CodeAlpha cloud task so the internship minimum-task requirement is met.
